# 실행 증거

계획 2.0부터는 마일스톤별 `m<N>.md`에 실행 명령·exit code·환경·결과·미검증을 짧게 남긴다. 기존 BASE/BE/FE 카드별 `<id 소문자>.md`는 당시 실제 기준 SHA, 환경, 실행 명령/exit code, 정상·반례 결과, 산출물, 미검증 범위와 다음 조건을 남긴다. 계획이나 테스트 소스의 존재를 실행 성공으로 취급하지 않는다. private 원문·token·prompt·DB 연결문자열을 기록하지 않는다.

기존 카드 증거는 BASE-01–03, BE-01–11·16–21, FE-01–02가 남아 있다. 제거된 Core·판단·추출·구조(CORE-01–16, BE-12–15)의 증거는 Git 이력에 있다.
