# M4 · 할일과 일정

상태: **구현·로컬·원격 Linux CI 검증 완료. 사용자 인수는 아직.** 원격 run `36535764940`(commit `7693932`)은 4개 job 모두 성공했다. 운영 DB·배포·실제 사용자 자료는 다루지 않았다. 백엔드(BE-09·10) 코드는 바꾸지 않았다.

## 범위

**할일** 목록(상태 필터·목록에서 바로 완료·페이지)·생성·상세·수정, 상태 전이(서버 표와 같은 허용 이동만 버튼으로 제공), 완료 이력, 결과 기록(완료에 연결된 새 기록), 맥락 연결(활성 프로젝트 맥락만), 기한(없음/날짜/날짜+시각+시간대). **일정** 월간 그리드와 날짜별 목록(URL `?month=`, 취소 포함 토글), 생성·상세·수정, 취소·복구, 시간 지정/종일, 시간대, 겹침 표시. 메뉴에 "할일", "일정"을 추가했다.

## 설계 결정

- **시간은 서버 저장 값 그대로 보이되 브라우저에서 미리 판별한다.** `shared/time.ts`가 어떤 시간대의 벽시계 시각이 (0) 시계 변경으로 건너뛰어졌는지, (1) 하나인지, (2) 시계를 되돌리는 날 두 번 있는지를 계산한다. 건너뛴 시각은 저장 전에 설명과 함께 막고, 두 번 있는 시각은 "먼저/나중" 중 고르게 해 그 offset을 서버에 보낸다. 서버 검증이 최종 기준이고 화면은 사용자가 왜 막혔는지 알려 주기 위한 것이다.
- **일정의 날짜 귀속은 보는 사람의 시간대 기준이다.** 다른 시간대의 일정은 원래 시간대와 내 시간대를 함께 보여 주고, 월간 그리드에서는 내 시간대의 날짜로 놓는다. 종일 일정은 시간대와 무관하게 날짜를 그대로 쓴다.
- **끝 시각은 배타적 구간**(직전 순간이 속한 날까지)으로 날짜를 계산한다. 종일 일정의 끝 날짜는 화면에서 포함, 서버에는 다음 날(배타)로 보낸다.
- **할일 맥락은 서버 규칙(활성 `PROJECT` 맥락만)에 맞춰** 선택지를 제한하고 이유를 안내한다. 처음에는 모든 맥락을 보여 줘 서버가 거부했고 E2E가 잡았다.
- 낡은 화면에서 전이·취소를 눌러 충돌하면 안내 후 최신 상태를 다시 불러온다. 수정 충돌은 M2·M3와 같이 초안을 남기고 최신 내용을 보여 준 뒤 "최신 버전 위에 저장"으로만 덮어쓴다.
- 캐시 key는 모두 `["user", 사용자 id, …]`로 시작한다.

## 개발 중 잡은 결함

- 날짜 표시 함수가 `Intl`이 허용하지 않는 옵션 조합(`dateStyle`+`weekday`)을 써서, 기한이 날짜인 할일의 상세 화면이 오류 화면으로 깨졌다.
- 할일 맥락 선택지가 서버 규칙과 어긋났다(위 참조).

할일 시나리오(격리 PostgreSQL, 실제 API): 입력 오류와 더블클릭 1건 생성, **원문에서 만든 완료 할일이 원문 수정 뒤에도 완료 상태로 남음**, 허용된 이동만 제공(완료된 할일은 다시 열기만 가능), 결과 기록이 새 기록으로 저장되고 같은 완료에는 한 번만, 다시 열고 완료하면 새 결과 가능·이전 결과 유지, 수정의 두 탭 충돌(초안 유지), 낡은 목록에서의 완료 거부와 최신 상태 반영, 날짜+시각 기한과 프로젝트 맥락 연결, **뉴욕 2028-03-12 02:30(건너뜀) 거부와 2028-11-05 01:30(두 번) 선택 강제**, 상태 필터와 55건 페이지, 다른 계정의 404와 320px.

일정 시나리오: 입력 오류(끝이 시작보다 빠름)와 월간 그리드 표시, **윤일(2028-02-29)을 지나는 종일 일정이 덮는 날마다 표시되고 마지막 날 다음 날은 빠짐**, **서머타임 시작일 건너뛴 시각 거부와 종료일 두 번 있는 시각의 선택이 서버에 실제로 반영됨(선택한 쪽의 UTC 시각, 01:30~03:30이 실제 2시간)**과 수정 화면에서 선택 복원, 다른 시간대 일정의 이중 표시와 내 시간대 날짜 귀속, 겹침 표시, 취소 숨김·취소 포함 토글·복구와 낡은 화면의 복구 거부, 수정 충돌, 달 이동과 잘못된 달 파라미터, 다른 계정의 404와 320px.

## 미검증·제한

- 일정을 다른 사용자의 시간대 규칙 변경(과거 tzdata 개정)으로 재해석하는 경우는 다루지 않는다. 서버는 저장한 offset을 기준으로 하며 화면은 그 값을 보여 준다.
- 월간 그리드는 하루 셀에 일정을 모두 나열한다. 일정이 매우 많은 날의 접힘·"더 보기"는 없다(API는 500건 초과 기간을 거부하고 화면이 안내한다).
- 주간·일간 보기, 일정 드래그, 반복 일정, 알림은 없다.
- 할일과 일정을 서로 연결하는 기능(BE에는 없음)은 다루지 않는다.
- 결과 기록이 만든 기록의 unit을 자동으로 맥락에 연결하지는 않는다.
- 스크린리더 실제 읽기와 강제 색상 모드는 검증하지 않았다.
- 사용자 ACCEPTED는 아직이다.
