상태: **VERIFIED**. FE-01 선행 BASE-02는 VERIFIED. 2026-09-25 KST macOS/Node 24.18.0과 Linux GitHub Actions에서 합성 표본만 검증했다. 구현 `79e6d03`, 빌드 수정 `6d01d0c`.

## 구현과 계약

- 기존 `design-system` token, theme, lock, recipe를 UI 패키지의 Button/Field/TextArea/Check/Select/Dialog/Notice/Status/Card/Table/Page/Stack/Cluster/Empty에 연결했다. `apps/web`은 Vite/React 상태 갤러리이며 W01·W26은 화면 표본이고 로그인·설정 서버 기능은 연결하지 않았다.
- `theme-init.js`가 React 부팅 전에 기기 선호를 반영한다. 시스템 모드 변화와 저장된 선택, 다른 탭의 저장 변경을 반영한다. 보존된 `policy.json`은 Paper 기본판의 frozen 기준이고 `themes.json` 1.1은 Dark 확장판이다.
- `scripts/plan/check.mjs`는 FE-01 착수 이후 새 웹 실행기에 필요한 `index.html`·`vite.config.ts`만 과거 정리 목록의 부재 검사에서 제외한다. 다른 정리 항목은 계속 검사한다.
- UI 접근성은 연결된 라벨·설명·오류, native dialog의 Escape와 focus 복귀, busy/disabled activation 차단, 선택/경고의 텍스트 표현을 사용한다. 이것은 범위 제한 검증이며 스크린리더 전수 인증이 아니다.
