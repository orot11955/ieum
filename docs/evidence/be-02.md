# BE-02 · 인증 adapter 호환성

상태: **IMPLEMENTED**, Linux CI 결과 대기 (2026-09-24 KST). 선행 BE-01/BASE-03은 VERIFIED다. 구현·시험 범위와 실제 명령은 [auth spike 보고서](auth-spike-report.md)에 기록했다.

Nest 12/Fastify 5의 native auth 경계, `auth` vendor schema/migration, 업무 `AuthPort`, 공개 가입 차단, MFA 및 즉시 세션 철회 반례를 구현·검증했다. 격리 PostgreSQL만 변경했으며 운영 DB·계정·배포에는 영향이 없다. CI PostgreSQL job이 통과하면 VERIFIED로 갱신한다. BE-03은 이 schema를 auth 전용 영역으로 유지하며 업무 role/RLS를 추가한다.
