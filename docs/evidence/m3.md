# M3 · 맥락

상태: **구현·로컬 검증 완료. 원격 CI와 사용자 인수는 아직.** 운영 DB·배포·실제 사용자 자료는 다루지 않았다.

## 범위

맥락 목록(이름 검색, 보관 포함 토글, cursor 페이지)·새 맥락·상세(목적·범위·연결된 기록·관계)·수정(새 identity revision)·보관, 기록 상세의 unit 표에서 다중 맥락 연결(대표/보조/배경, 대표는 최대 하나), 맥락 간 관계(상위·하위·관련) 추가·끊기. 메뉴에 "맥락"을 추가했다.

같은 변경에 포함한 것: 테마 기본값을 Paper light로 바꿨다(기기가 다크여도 처음은 light, "시스템 설정"을 고르면 기기를 따른다). 이 기록의 사용자 비밀번호 최소 길이 9자 변경(사용자가 직접 한 수정: auth·복구 CLI·서비스·계약·초대 화면)도 같은 커밋에 들어 있다.

## 계약 변경 (화면을 붙이며 드러난 결함)

맥락 상세의 `memberships`에 unit ID만 있어 어느 기록의 어떤 문장인지 화면에서 알 수 없었다. `captureId`, `captureTitle`, `excerpt`(앞 300자, code point 기준이라 이모지 중간에서 잘리지 않음), `truncated`를 더했다. 백엔드는 기존 쿼리에 조인만 추가했고 권한·RLS 경로는 그대로다. OpenAPI와 생성 타입을 다시 만들었다. `identity.integration.test`에 새 필드 검증을 추가했다.

## 설계 결정

- **소속 편집은 통째 교체 API**(`POST /units/:id/memberships`)라서, 충돌 시 로컬 편집을 남기지 않고 최신 연결을 불러와 다시 검토하게 한다. 다른 탭이 추가한 연결을 조용히 지우지 않기 위해서다. 충돌 안내는 편집기가 다시 만들어져도 남도록 부모에 둔다(처음 구현에서 안내가 사라지는 결함을 E2E가 잡았다).
- 새로 연결할 수 있는 것은 활성 맥락뿐이다. 이미 연결된 보관·대체 맥락은 "(보관됨)"으로 표시되어 해제할 수 있다.
- 맥락 이름 조회는 모든 맥락(최대 20페이지)을 읽는다. 한도에 닿으면 일부만 표시한다고 알린다.
- 맥락 수정의 충돌 처리는 기록 수정(M2)과 같다: 작성 중 내용을 남기고 최신 내용을 보여 준 뒤 "최신 버전 위에 저장".
- 캐시 key는 모두 `["user", 사용자 id, …]`로 시작한다.

## 실제 실행 (Node 24.18.0, macOS, Colima PostgreSQL 18.4)

| 명령 | exit | 결과 |
|---|---:|---|
| `npm run prep:check`, `pnpm contracts:check`, `pnpm lint`, `pnpm format:check`, `pnpm typecheck` | 0 | |
| `pnpm test:unit`, `pnpm build`, `pnpm api:smoke` | 0 | |
| `pnpm --filter @ieum/backend test:db` | 0 | 32개 |
| `pnpm --filter @ieum/api test:identity` | 0 | 새 필드 검증 포함 |

M3 시나리오 10개(격리 PostgreSQL, 실제 API): 입력 오류 안내와 더블클릭 1건 생성, 한 unit을 두 맥락에 연결하고 대표 둘을 거부, 두 탭에서의 오래된 소속 저장 충돌과 최신 연결 재로딩, 관계 추가·양쪽 표시·상위 순환 거부·끊기, 맥락 수정과 두 탭 충돌(초안 유지·최신 위에 저장), 보관된 맥락(목록 제외·연결 유지·새 연결 불가·수정 불가), 화면에서 보관 확인, 검색과 55건 페이지, 다른 계정의 URL 접근 404와 빈 목록, 320px 폭 넘침 없음. 테마 테스트는 기기가 다크여도 기본이 light임을 확인한다.

## 미검증·제한

- unit 사이 관계(`thought-relations`: 근거·반박 등)는 화면이 없다. 계획의 M3 범위는 맥락 간 관계였다.
- 맥락 상세에서 기록을 "이 맥락에서 빼기"만 하는 단축 동작은 없고, 연결 편집 창에서 해제한다.
- 맥락이 1,000개를 넘는 경우의 연결 창 성능과 이름 검색 기반 선택은 만들지 않았다.
- 상위·하위 관계를 그래프로 보는 화면은 없다(목록으로만 표시).
- 스크린리더 실제 읽기, 강제 색상 모드는 검증하지 않았다.
- 사용자 ACCEPTED와 원격 CI는 아직이다.
